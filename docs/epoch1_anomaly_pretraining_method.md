## 1. Purpose of Epoch 1

Epoch 1 operates as a **single-epoch anomaly-pretraining stage** designed to learn complex surface-to-subsurface physical couplings before transitioning to direct absolute-temperature prediction.

```text
Epoch 1:
The model predicts subsurface temperature anomalies relative to a
training-derived climatological baseline.

Epoch 2 onward:
The pretrained representation is retained, but the prediction target
is changed to direct absolute subsurface temperature.
```

By constraining initial gradient updates to residual temperature departures, the network is prevented from squandering its representational capacity on rediscovering the first-order vertical thermal stratification (the bulk thermocline profile). Instead, the model immediately focuses its spatial and vertical self-attention mechanisms on dynamic mesoscale deviations (eddies, upwelling fronts, wind-driven mixing).

---

## 2. Mathematical Formulation

During Epoch 1, the training target and model prediction are defined by the following exact formulations:

$$\Delta T = T_{\text{true}} - T_{\text{clim}}$$

$$T_{\text{pred}} = T_{\text{clim}} + \Delta T_{\text{pred}}$$

### Variable Definitions

| Variable | Tensor Shape | Physical Dimension | Definition & Source |
| :--- | :--- | :--- | :--- |
| **$T_{\text{true}}$** | $[B, 15]$ | $^\circ\text{C}$ | Ground truth ocean temperature from the GLORYS12V1 reanalysis at 15 discrete physical depth levels ($0\,\text{m}$ to $1000\,\text{m}$). |
| **$T_{\text{clim}}$** | $[B, 15]$ | $^\circ\text{C}$ | Spatially localized, day-of-year seasonal baseline temperature generated by the parametric Fourier climatology model. |
| **$\Delta T$** | $[B, 15]$ | $^\circ\text{C}$ | True temperature anomaly departure from the climatological baseline for that specific geographic location and day. |
| **$\Delta T_{\text{pred}}$** | $[B, 15]$ | $^\circ\text{C}$ | Neural network predicted temperature anomaly output from `anomaly_head`. |
| **$T_{\text{pred}}$** | $[B, 15]$ | $^\circ\text{C}$ | Reconstructed absolute physical temperature (`absolute_temp = climatology + anomaly_mean`). |

## 3. Fourier Climatology Method

The climatological baseline $T_{\text{clim}}$ is calculated via a frozen, pre-fitted **2nd-order harmonic (Fourier) expansion** parameterizing the annual and semi-annual seasonal cycle.

### Mathematical Formulation
For any latitude, longitude, depth level $z_d$, and day of year:

$$T_{\text{clim}}(\text{lat}, \text{lon}, z_d, \phi) = a_0 + a_1\sin(\phi) + b_1\cos(\phi) + a_2\sin(2\phi) + b_2\cos(2\phi)$$

with the seasonal phase angle defined as:

$$\phi = \frac{2\pi(\text{doy} - 1)}{365.25}$$

where:
* $\text{doy} \in [1, 366]$ is the day-of-year extracted from the Gregorian calendar timestamp.
* $\text{seasonal\_time} = (\text{doy} - 1) / 365.25 \in [0, 1)$.
* $\phi$ ($1\times$ frequency) captures the primary annual solar cycle (summer warming / winter cooling).
* $2\phi$ ($2\times$ frequency) captures the semi-annual cycle, physically mandatory in the North Indian Ocean and Bay of Bengal due to the biannual monsoon wind reversals (Southwest Monsoon vs. Northeast Monsoon).

### Basis Vector
The 5-component harmonic basis vector is:

$$\mathbf{b}(\phi) = \begin{bmatrix} 1.0 & \sin(\phi) & \cos(\phi) & \sin(2\phi) & \cos(2\phi) \end{bmatrix}^T \in \mathbb{R}^5$$

### Grid and Depth Dimensions
* **Spatial Domain**: Latitude $5.0^\circ\text{N} \le \text{lat} \le 30.0^\circ\text{N}$, Longitude $45.0^\circ\text{E} \le \text{lon} \le 105.0^\circ\text{E}$ at $0.25^\circ$ grid spacing.
  * $N_{\text{lat}} = 101$ coordinates
  * $N_{\text{lon}} = 241$ coordinates
* **Vertical Depths**: 15 discrete levels ($N_{\text{depths}} = 15$):
  $$z \in [0, 5, 10, 20, 30, 50, 75, 100, 125, 150, 200, 300, 500, 700, 1000]\,\text{metres}$$

### Fitting Procedure & Regularization
* Implemented in [`fit_climatology.py`](file:///Users/parvninama/Programs/SIH/dsvit_ocean/fit_climatology.py) and [`HarmonicClimatology.fit_from_samples`](file:///Users/parvninama/Programs/SIH/dsvit_ocean/upgraded/climatology.py#L62-L136).
* Fit using **Ridge regression** with Tikhonov regularization parameter $\lambda = 10^{-3}$:
  $$\mathbf{w}_{i, j, d} = \left(\mathbf{X}^T \mathbf{X} + \lambda \mathbf{I}_5\right)^{-1} \mathbf{X}^T \mathbf{y}$$
* **Fallback Rule**: If an individual $0.25^\circ \times 0.25^\circ$ ocean cell contains fewer than 5 valid historical training observations at depth $d$, the coefficients fall back to the regional basin-wide profile `global_fallback[d]`.

### Storage & Retrieval
* **Disk Format**: Saved via `np.savez_compressed` to `checkpoints/climatology.npz`. Stores `coeffs` $[101, 241, 15, 5]$ and `global_fallback` $[15, 5]$.
* **Training & Validation Retrieval**: Handled on-device via `HarmonicClimatology.lookup_torch`:
  1. Geographic coordinates are mapped to grid indices:
     $$\text{lat\_idx} = \text{clamp}\left(\left\lfloor \frac{\text{lat} - 5.0}{0.25} + 0.5 \right\rfloor, 0, 100\right)$$
     $$\text{lon\_idx} = \text{clamp}\left(\left\lfloor \frac{\text{lon} - 45.0}{0.25} + 0.5 \right\rfloor, 0, 240\right)$$
  2. The $15 \times 5$ coefficient matrix is gathered from GPU buffers: $\mathbf{W}_b = \text{Coeffs}[\text{lat\_idx}, \text{lon\_idx}]$.
  3. Tensor inner product yields the baseline temperature in $^\circ\text{C}$:
     $$T_{\text{clim}} = \sum_{k=1}^5 \mathbf{W}_{b, :, k} \cdot \mathbf{b}_k(\phi) \in \mathbb{R}^{B \times 15}$$

## 4. Data Used to Construct Climatology

To maintain complete methodological integrity and eliminate data leakage, the climatological prior is constructed under strict data boundaries:

```text
Climatology fitting:
GLORYS training partition only

Not used:
GLORYS validation
GLORYS held-out test
Argo
```

### Protocol Specifications
1. **Partition Isolation**: Fitted strictly on the training partition ($1,732,052$ samples spanning February 1, 2023 to June 7, 2024). Validation ($192,450$ samples) and held-out test ($481,126$ samples) are completely excluded.
2. **Independent Argo Float Exclusion**: No in-situ Argo profiling float data is ever accessed, read, or referenced during climatology generation.
3. **Bathymetric Depth Masking**: For shallow coastal waters, samples where `depth_mask[:, d] == 0` (indicating the level lies beneath the seabed) are excluded from the normal equations for depth $d$.

## 5. Epoch-1 Model Inputs

The neural network receives 7 physical surface observation channels, 1 binary spatial surface mask, and continuous spatiotemporal coordinate encodings.

```text
Input Tensor Stream:
1. Surface Physical Data : [B, 7, 11, 11]  (SST, SSS, SLA, U_curr, V_curr, U_wind, V_wind)
2. Spatial Land/Sea Mask : [B, 1, 11, 11]  (1 = ocean, 0 = land)
3. Geographic Embeddings : [B, 128]        (Continuous spherical embedding of Lat/Lon)
4. Learned Seasonal Embed: [B, 128]        (Neural network periodic embedding of DOY)
```

### Exact Surface Channels
1. **SST**: Sea Surface Temperature ($^\circ\text{C}$)
2. **SSS**: Sea Surface Salinity ($\text{PSU}$)
3. **SLA**: Sea Level Anomaly ($\text{m}$)
4. **U_curr**: Eastward surface geostrophic current ($\text{m/s}$)
5. **V_curr**: Northward surface geostrophic current ($\text{m/s}$)
6. **U_wind**: Eastward $10\,\text{m}$ surface wind component ($\text{m/s}$)
7. **V_wind**: Northward $10\,\text{m}$ surface wind component ($\text{m/s}$)

### Critical Distinction: Fourier Climatology vs. Neural Seasonal Encoding

It is vital to distinguish the two distinct seasonal representations operating in Epoch 1:

* **Fourier Climatology ($T_{\text{clim}}$)**:
  * Non-learned, frozen analytical Fourier model.
  * Direct lookup table producing a physical baseline temperature vector $[B, 15]$ in $^\circ\text{C}$.
  * Does **not** enter the Transformer latent space; combined additively with the final output.
* **Learned Neural Seasonal Encoding (`SeasonalEncoding`)**:
  * Implemented in [`upgraded/seasonal_encoding.py`](file:///Users/parvninama/Programs/SIH/dsvit_ocean/upgraded/seasonal_encoding.py).
  * Takes $\text{seasonal\_time} \in [0, 1)$, evaluates $[\sin(\phi), \cos(\phi), \sin(2\phi), \cos(2\phi)]$, and projects through a learned MLP:
    $$\mathbb{R}^4 \xrightarrow{\text{Linear}(4, 32)} \text{GELU} \xrightarrow{\text{Linear}(32, 128)} \mathbb{R}^{128}$$
  * Added directly into the Transformer spatial token sequence to inform self-attention weights of seasonal stratification patterns.

## 6. Model Architecture Used in Epoch 1

The architecture implements a dual-stage **Inception-Vision-Transformer (ViT)** topology:

```text
Surface Patch [B, 8, 11, 11]
         │
         ▼
Inception-style CNN Encoder
         │
         ▼
6 × 6 Latent Representation [B, 128, 6, 6]
         │
         ▼
36 Spatial Tokens [B, 36, 128]
  + 2D Positional Encoding
  + Geographic Encoding [B, 128]
  + Neural Seasonal Encoding [B, 128]
         │
         ▼
Prepend Learnable Target Token [B, 37, 128]
         │
         ▼
Spatial Transformer (3 Layers, 4 Heads, Dim 128)
         │
         ▼
Extract Target Context Token [B, 128]
         │
         ▼
Condition with Physical Depth Encodings (15 Depths)
         │
         ▼
15 Depth Tokens [B, 15, 128]
         │
         ▼
Vertical Transformer (2 Layers, 4 Heads, Dim 128)
         │
         ▼
Anomaly Head [B, 15] & Uncertainty Heads
```

### Structural Parameters

| Component | Specification in Code (`upgraded/model.py`) |
| :--- | :--- |
| **Input Channels** | $8$ ($7$ surface physical variables $+ 1$ binary surface mask) |
| **Encoder Architecture** | Multi-branch Inception blocks ($1\times 1$, $3\times 3$, cascaded $3\times 3$, and $3\times 3$ avg pool) |
| **Spatial Downsampling** | $11 \times 11 \to 6 \times 6$ via stride-2 conv ($32$ channels) |
| **Latent Dimension ($C$)**| $128$ |
| **Spatial Tokens** | $36$ tokens (from flattened $6 \times 6$ grid) |
| **Target Token** | $1$ learnable parameter $[1, 1, 128]$, initialized via truncated normal ($\sigma = 0.02$) |
| **Spatial Transformer** | **$3$ Encoder Layers**, **$4$ Heads**, $\text{FFN ratio} = 2.0$ ($\text{dim} = 256$), $\text{dropout} = 0.10$, Pre-LN |
| **Depth Encoding** | Normalized logarithmic depth: $\log(1 + z) / \log(1 + 1000) \to \text{MLP}(1 \to 32 \to 128)$ |
| **Depth Tokens** | $15$ tokens created via: $\text{target\_context}[B, 1, 128] + \text{depth\_embeddings}[1, 15, 128]$ |
| **Vertical Transformer**| **$2$ Encoder Layers**, **$4$ Heads**, $\text{FFN ratio} = 2.0$ ($\text{dim} = 256$), $\text{dropout} = 0.10$, Pre-LN |
| **Decoder Branch** | Parallel Inception CNN decoder reconstructing $[B, 7, 11, 11]$ surface data from latent |

## 7. Epoch-1 Output Heads

The model features three dedicated output heads branching from the 15 depth tokens $[B, 15, 128]$:

### 1. Anomaly Head
```text
Anomaly head:
[B, 15, 128] → Linear(128, 64) → GELU → Linear(64, 1) → [B, 15]
```
* **Output**: $\Delta T_{\text{pred}} \in \mathbb{R}^{B \times 15}$
* Represents the predicted temperature anomaly relative to the climatological baseline in $^\circ\text{C}$.

### 2. Correlated Uncertainty Heads
The model does not assume depth errors are uncorrelated. It estimates a low-rank multivariate normal covariance structure across depth:

$$\mathbf{\Sigma} = \mathbf{D} + \mathbf{L} \mathbf{L}^T$$

* **Diagonal Variance Head ($\mathbf{D}$)**:
  $$\text{Linear}(128, 64) \to \text{GELU} \to \text{Linear}(64, 1) \to \text{Softplus} + 10^{-4} \to \mathbf{D} \in \mathbb{R}^{B \times 15}$$
  Guarantees strictly positive diagonal variance for every depth level.
* **Low-Rank Factor Head ($\mathbf{L}$)**:
  $$\text{Linear}(128, 64) \to \text{GELU} \to \text{Linear}(64, 3) \to \mathbf{L} \in \mathbb{R}^{B \times 15 \times 3}$$
  Captures vertical correlation across depths with $\text{rank} = 3$.

## 8. Epoch-1 Losses

The training objective is a composite 5-component loss function implemented in [`upgraded/losses.py`](file:///Users/parvninama/Programs/SIH/dsvit_ocean/upgraded/losses.py):

$$\mathcal{L}_{\text{total}} = \lambda_{\text{anom}} \mathcal{L}_{\text{anom}} + \lambda_{\text{abs}} \mathcal{L}_{\text{abs}} + \lambda_{\text{rec}} \mathcal{L}_{\text{rec}} + \lambda_{\text{grad}} \mathcal{L}_{\text{grad}} + \lambda_{\text{unc}} \mathcal{L}_{\text{unc}}$$

### Configured Loss Components

```text
anomaly loss       = 1.00
absolute loss      = 0.50
reconstruction     = 0.10
gradient loss      = 0.10
uncertainty/NLL    = 0.10
```

| Loss Component | Weight | Mathematical Definition | Prediction Used | Target Used | Mask Applied |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **$\mathcal{L}_{\text{anom}}$** | $1.00$ | Masked Huber Loss ($\delta = 1.0$) | $\Delta T_{\text{pred}}$ | $\Delta T = T_{\text{true}} - T_{\text{clim}}$ | `depth_mask` |
| **$\mathcal{L}_{\text{abs}}$** | $0.50$ | Masked Huber Loss ($\delta = 1.0$) | $\hat{T}_{\text{abs}} = T_{\text{clim}} + \Delta T_{\text{pred}}$ | $T_{\text{true}}$ | `depth_mask` |
| **$\mathcal{L}_{\text{rec}}$** | $0.10$ | Masked Mean Squared Error | $\hat{\mathbf{S}}_{\text{recon}}$ | $\mathbf{S}_{\text{orig}}$ ($7$ channels) | `surface_mask` |
| **$\mathcal{L}_{\text{grad}}$** | $0.10$ | Masked Finite-Difference MSE | $\frac{\hat{T}_{d+1} - \hat{T}_d}{\Delta z_d}$ | $\frac{T_{d+1} - T_d}{\Delta z_d}$ | `pair_mask` |
| **$\mathcal{L}_{\text{unc}}$** | $0.10$ | Multivariate Gaussian NLL | $\Delta T_{\text{pred}}, \mathbf{D}, \mathbf{L}$ | $\Delta T$ | `depth_mask` |

### Huber Loss Formulation
For residual error $e = |y - \hat{y}|$:
$$\mathcal{H}_\delta(e) = \begin{cases} 0.5 \, e^2 & \text{if } e \le \delta \\ \delta \, (e - 0.5\,\delta) & \text{otherwise} \end{cases} \quad (\delta = 1.0^\circ\text{C})$$

## 9. Vertical Gradient Treatment

Vertical thermal stratification consistency is enforced via physical finite differences across target depth levels in [`upgraded/losses.py`](file:///Users/parvninama/Programs/SIH/dsvit_ocean/upgraded/losses.py#L49-L68):

$$g_{\text{pred}, d} = \frac{\hat{T}_{d+1} - \hat{T}_d}{z_{d+1} - z_d}, \qquad g_{\text{true}, d} = \frac{T_{d+1} - T_d}{z_{d+1} - z_d}$$

$$\mathcal{L}_{\text{grad}} = \frac{\sum_{d=1}^{14} (g_{\text{pred}, d} - g_{\text{true}, d})^2 \cdot m_{\text{pair}, d}}{\sum_{d=1}^{14} m_{\text{pair}, d} + 10^{-8}}$$

### Implementation Rules
1. **Actual Physical Depth Spacing ($\Delta z$)**: Evaluated using true vertical separation distances in metres:
   $$\Delta z \in [5, 5, 10, 10, 20, 25, 25, 25, 25, 50, 100, 200, 200, 300]\,\text{metres}$$
2. **Adjacent-Depth Masking**:
   $$m_{\text{pair}, d} = \text{depth\_mask}[d] \times \text{depth\_mask}[d+1]$$
   Ensures gradients are calculated **only** when both adjacent depth levels represent real water.
3. **Absolute Temperature Basis**: Gradients are calculated from **reconstructed absolute temperatures** ($\hat{T}_{\text{abs}}$ vs. $T_{\text{true}}$), directly constraining physical thermocline sharpness.
4. **Seabed Immunity**: Shallow profiles on continental shelves are automatically truncated at the seabed; no subterranean points ever enter the gradient loss.

## 10. Normalization Protocol

Normalization is applied strictly to surface input channels to preserve physical dimensions across target outputs.

### Protocol Details
* **Normalized Variables**: Only the 7 surface input channels (SST, SSS, SLA, U_curr, V_curr, U_wind, V_wind).
* **Partition Source**: Normalization statistics (mean $\mu_c$, standard deviation $\sigma_c$) are computed **strictly from the training partition** (via `compute_training_norm_stats` in [`upgraded/dataset.py`](file:///Users/parvninama/Programs/SIH/dsvit_ocean/upgraded/dataset.py#L159-L204)).
* **Ocean-Only Calculation**: Land cells are masked out during statistical accumulation:
  $$\mu_c = \frac{\sum_{i \in \text{ocean}} S_{c, i}}{N_{\text{ocean}}}, \qquad \sigma_c = \sqrt{\frac{\sum_{i \in \text{ocean}} (S_{c, i} - \mu_c)^2}{N_{\text{ocean}}}}$$
* **Application Timing**: Applied on-the-fly during dataset indexing (`__getitem__`):
  $$S_{\text{norm}, c} = \frac{S_c - \mu_c}{\max(\sigma_c, 10^{-8})} \times \text{surface\_mask}$$
* **Target Temperature ($T_{\text{true}}$)**: **NOT NORMALIZED**. Preserved in raw degrees Celsius ($^\circ\text{C}$).
* **Anomaly Target ($\Delta T$)**: **NOT NORMALIZED**. Expressed in physical degrees Celsius anomaly ($^\circ\text{C}$).

## 14. Why the Epoch-1 Stage Exists

```text
Epoch 1 provides a warm-start representation-learning stage in which
the network learns surface-to-subsurface relationships while the
large-scale seasonal/depth background is represented by the
training-derived climatological prior.
```

The physical motivation rests on the fact that vertical ocean temperature profiles have high static variance ($>20^\circ\text{C}$ difference between surface and deep abyss). Training an unconstrained network directly on raw absolute temperature frequently causes initial gradients to collapse toward fitting the static vertical profile while ignoring subtle surface dynamic signals (SLA and currents).

By anchoring the baseline with Fourier climatology during Epoch 1, the model is compelled to allocate attention weights to active mesoscale phenomena.

```text
The direct-temperature stage is an experimental continuation from
the anomaly-pretrained representation, and its benefit must be
determined empirically.
```

## 15. Transition Specification

The architectural and procedural transition from Epoch 1 (Anomaly Pretraining) to Epoch 2 (Direct Temperature Prediction) is specified as follows:

```text
                 EPOCH 1
        Anomaly Pretraining
                 │
                 ▼
        ΔT = T - T_clim
                 │
                 ▼
       Save epoch1 checkpoint
                 │
                 ▼
          Change output head
                 │
        Remove Fourier path
                 │
                 ▼
                 EPOCH 2
        Direct Temperature
                 │
                 ▼
              T_pred
```

### Component Transition Breakdown

```text
KEPT:
shared encoder
spatial Transformer
vertical Transformer
depth representation
other compatible learned representations

CHANGED:
anomaly output head
target construction
prediction formulation
climatology/Fourier prediction pathway

REMOVED AFTER EPOCH 1:
Fourier climatology dependency
anomaly target construction
T_clim + ΔT reconstruction
```

## Implementation Notes / Discrepancies

1. **Current Multi-Epoch Driver Setup**:
   * In the existing code base (`configs/upgraded_model.yaml` and `scripts/run_training_4yr.py`), anomaly-based residual modeling is configured by default for all 50 epochs (`use_anomaly_target: true`).
   * The single-epoch anomaly-pretraining protocol requires decoupling the driver so that after Epoch 1 completes, the checkpoint is exported as `checkpoints/epoch1_anomaly_pretrain.pt` and the model switches to direct absolute temperature prediction for Epoch 2 onward.
2. **Checkpoint Naming Convention**:
   * Current training writes `checkpoints/epoch_001.pt`, `latest.pt`, and `best.pt`.
   * For the explicit pretraining transition pipeline, the checkpoint must be explicitly saved or linked to `checkpoints/epoch1_anomaly_pretrain.pt`.
3. **Loss Weighting in Absolute vs Anomaly Mode**:
   * In Epoch 1, `lambda_anomaly` is $1.0$ and `lambda_absolute` is $0.5$.
   * During the direct-temperature transition in Epoch 2, `lambda_anomaly` and the Fourier climatology pathway will be deactivated, shifting the primary supervision weight entirely to direct absolute temperature Huber loss.
